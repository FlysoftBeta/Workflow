# UI 规范
本文件规定视觉、密度、布局和组件交互；用户可见行为以 [product.md](product.md) 为准。实现使用 Jetpack Compose + Material 3 Expressive（`androidx.compose.material3` 1.5.0-alpha，可用 Expressive API），minSdk 28，不依赖更高 API 的平台特性。与 product.md 之间的缺口或冲突列在 §8，未擅自改变行为。

## 1. 原则与 tokens
- **一层 chrome**：每个区域只有一行 header，可以是 Stack 的 Tab 行，也可以是同高的标题行。不使用 App Bar、NavigationBar/Rail、Panel 标题栏、面包屑、状态行。
- **不写 helper text**：不放口号、欢迎语、说明段落。状态文字只在异常时出现，并附一个可执行动作。长按 icon button 显示 `PlainTooltip`（内容即 contentDescription）。
- **不暴露技术细节**：不显示包名、内核名、PID、端口、路径映射、面板数、协议字段。确需时放进"更多 → 复制… / 详情"。每一种拖放都有等价的菜单项（移动到… / 附加到对话 / 复制路径）。
- **不得重现旧版问题**（见 `docs/report/initial/audit-device-ux.md`）：带文字标签的 Rail；口号和"继续工作"大卡片；顶栏 + 面板头 + 状态行层层叠加；三处设置入口；48dp 的扁平文件列表，且露出 `.bak`；显示包名；禁用控件下方的解释句；原始 JSON 审批；用 BottomSheet 选模型
- **目标窗口**：见下表。宽度 < 600dp 时单列降级（§3.5）。横屏弹出 IME 后只剩约 350dp 高，此时仍须可用（§2.3）。输入只有触控和软键盘，没有 hover；硬件键盘为可选。

| 缩放 | 横屏可用区域 | 竖屏可用区域 |
| --- | --- | --- |
| 261 dpi（当前） | 1177 × ≈675 dp | 736 × ≈1115 dp |
| 320 dpi（原生） | 960 × ≈540 dp | 600 × ≈900 dp |

### 1.1 密度 tokens（dp）
密度分两档：紧凑（默认）/ 标准，在"设置 → 外观"中切换。组件只读 `ui.design` 中的 tokens，不写死数值。

| Token | 紧凑 | 标准 | 用途 |
| --- | --- | --- | --- |
| `bar` | 36 | 44 | Tab 行、区域 header、查找条 |
| `iconBtn` 视觉/触控 | 32/36 | 40/48 | `LocalMinimumInteractiveComponentSize` 取触控值 |
| `icon` | 20（菜单/树 18） | 24 | |
| `treeRow` | 32 | 40 | 文件树、对话列表 |
| `listRow` 单/双行 | 36/48 | 48/64 | 会话视图、添加应用、设置（设置行固定 48） |
| `menuItem` | 36 | 44 | 下拉菜单 |
| `extraKeys` 行/键 | 40/34 | 48/40 | 终端特殊键 |
| `gap`/`padH`/`indent` | 4/12/12 | 6/16/16 | 区域缝与外边距 / 内容水平边距 / 树每级缩进 |

触控约定：
- 工具行中 icon button 的触控区就是其 36×36 视觉格，相邻按钮互不重叠。
- 全宽行整行都是触控区。
- 独立控件（发送、开关、滑块）≥ 40dp；Launcher 与悬浮窗中 ≥ 48dp。

### 1.3 颜色与图标
API 28 没有 dynamic color。以 app 图标主色 `#286B57` 为 seed，构建期用 material-color-utilities `SchemeTonalSpot`（contrast 0）生成配色，固化为 `ui.design` 常量。下表为评审用近似值，以生成结果为准。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| primary / onPrimary | #286B57 / #FFFFFF | #90D4BC / #00382A |
| primaryContainer / on | #ACF1D8 / #002117 | #04513E / #ACF1D8 |
| secondaryContainer / on | #CEE8DE / #0A1F19 | #354B43 / #CEE8DE |
| tertiaryContainer / on | #BEE9F9 / #001F28 | #214C59 / #BEE9F9 |
| surface / onSurface | #F4FBF8 / #171D1B | #0E1512 / #DDE4E1 |
| surfaceContainer Low/默认/High/Highest | #EEF5F2 / #E8EFED / #E2EAE7 / #DDE4E1 | #171D1B / #1B211F / #262B29 / #303634 |
| onSurfaceVariant / outline / outlineVariant | #3C4A44 / #6B7A75 / #BACAC4 | #BACAC4 / #84948E / #3C4A44 |
| error / errorContainer | #BA1A1A / #FFDAD6 | #FFB4AB / #93000A |
| 扩展 success / warning | #216C26 / #7D5800 | #8ED888 / #F7BD55 |

- **用法**：frame（窗口底、状态栏、导航栏）= `surfaceContainer`；区域内容 = `surface`；菜单、弹层、composer = `surfaceContainerHigh`；代码块 = `surfaceContainerHighest`；选中行 = `secondaryContainer`；焦点与进行中 = `primary`；success 用于 diff 的 + 和良好延迟；warning 用于"完全访问"、偏高延迟、冲突
- **主题**：跟随系统 / 浅 / 深。编辑器和终端都跟随主题。ANSI 16 色准备浅、深两套，浅色一套调暗到 ≥ 4.5:1。终端的背景 / 前景 / 光标 / 选区取 surface / onSurface / primary / primary 30%。
- **界面图标**：使用 Material Symbols Rounded（Apache-2.0，固定版本）。只把用到的 glyph 转为 vector drawable，附 LICENSE 与版本 manifest；不用已冻结的 `material-icons-extended` 1.7.8，不用图标字体，不用 CDN；默认 weight 400、fill 0，激活态 fill 1；文件类型图标按扩展名从同一套里映射，约 12 种
- **启动器图标**：来源 `/home/flysoft/projects/Workflow/build/icon-preview/icon.svg`：底色 `#D3EDDC`，三块圆角矩形分别为 `#286B57`/`#124936`/`#6B9D86`；转为 adaptive icon（前景置于 108dp 安全区，背景用纯色）和 legacy PNG；单色版用于 Home 按钮和悬浮球
- **三方应用图标**：由 PackageManager 在后台线程加载并缓存，原样显示；主线程不调用 `loadLabel`/`loadIcon`。

## 2. 全局 chrome
### 2.1 系统栏与角落按钮
- **系统栏**：调用 `enableEdgeToEdge()`；状态栏和 3 键导航栏用 frame 色，图标明暗随主题，不隐藏状态栏；根布局按 `WindowInsets.safeDrawing` 避让，含 cutout 与侧边导航栏；使用 `adjustResize` + `WindowInsets.ime`。API 28 没有 `WindowInsetsAnimation`，IME 引起的布局变化不做动画
- **角落簇**：Workbench 不设顶栏。全局入口组成"角落簇"，注入到恰好占据窗口角落的那一行 header 中，不单独占行；侧栏收起后，左上簇移到新的左上角那一行；Solo 只保留 ⌂、会话 chip、⚙；如果 Solo 面板本身就是设置，隐藏 ⚙；Launcher 只在右上放会话 chip（设置在 Launcher 中是一个图块）

| 角落 | 内容 | 行为 |
| --- | --- | --- |
| 左上（行首） | `⌂` Home · `◧` 侧栏开关 · 会话 chip | ⌂：回到 Launcher，保留状态。◧：开关 Files 的文件浏览器或 Chat 的对话列表。会话 chip：宽 64–120dp，显示持久 Session 名，或临时 Session 的开始时间（如"周日 14:32"）；点按打开会话视图，长按命名。 |
| 右上（行尾，前加 1dp 分隔） | `◨` 辅助区开关 · `⚙` 设置 | ◨：开关 Files 的对话面板或 Chat 的文件侧栏；有待确认请求时带 tertiary 圆点。⚙：在当前 Session 打开设置面板，已打开则聚焦。 |

### 2.2 统一工具行与 More 菜单
Tab 行结构：`[Tabs，横向滚动][⌄n 溢出][焦点 Panel 的外提按钮][⋯]`。
- 外提按钮随激活 Panel 变化。当 Tab 区剩余宽度 < 120dp 时，外提按钮按优先级从低到高折叠进 More 顶部。
- 文件浏览器、对话列表、对话列没有 Tab，用同高的 header 行代替。
- 查找条、冲突条只在需要时作为内容顶部的临时行出现。

| Panel | 外提按钮（优先级由高到低） | More ①资源组 |
| --- | --- | --- |
| 文本编辑器 | 保存（有草稿才可用）、撤销、重做、查找、附加到对话 | 复制路径 · 复制相对路径 · 在文件树中显示 · 附加到对话 · 在终端中打开所在目录 · 用其他应用打开 · ☐自动换行 · 放弃更改（error，需确认） |
| 图片 | 适应/原始大小 | 复制路径 · 在文件树中显示 · 附加到对话 · 用其他应用打开 · 分享 |
| 终端 | 新建终端；底部 Stack 另有 `⌄`/`⌃` 收起/展开 | 清屏 · 重命名 · 重启 · ☐常驻特殊键行 · 结束（error） |
| 代理/日志/连接 | 延迟测试 | 编辑配置 · 日志 · 连接 |
| 设置 | — | 编辑工作区配置 · 编辑环境配置 |
| 文件浏览器 | `＋`：新建文件 · 新建文件夹 ┆ 拍照 · 相册 · 设备文件（写入选中目录） | 筛选… · 全部折叠 · 刷新 · ☐显示隐藏文件 · 在终端中打开 |
| 对话 | 在 Files 中为 `⤢` 设为主要内容 | 重命名 · 分叉 · 复制为 Markdown · 归档 |

- **② 面板/布局组**：Stack 通用：向右拆分 · 向下拆分 · 移动到 ▸（各 Stack / 新 Stack）· 最大化/还原 · 关闭其他 · 关闭右侧 · 关闭已保存；文件浏览器：收起侧栏；Files 对话面板：设为主要内容 · 收起面板；Chat 主列：回到 Files · ☐文件侧栏
- **③ Session 组**（每个 More 的末尾）：新建 Session · 命名 Session… · 切换到 Chat/Files · 所有会话…
- **菜单形态**：用 Expressive 分组菜单，组间加 separator；如果 alpha 版的 `DropdownMenuGroup` 不稳定，改用 `HorizontalDivider`；每项带 18dp 图标；破坏性项放在组末，用 error 色；只在接入硬件键盘时右对齐显示快捷键；子菜单向侧边展开；长按 Tab 或树节点但不移动时，弹出同一份菜单（①②组）

### 2.3 IME 聚焦与 Back
- **IME 聚焦**：键盘弹出时，持有焦点的 Stack 在所在列内临时占满，同列其他 Stack 缩成 36dp 的 Tab 行；其他列只是变矮；键盘收起后恢复，这个临时状态不持久化；终端特殊键行紧贴在 IME 上方
- **Back**：依次关闭：菜单 / tooltip → 进行中的拖放 → 弹层 / sheet / 对话框 → 覆盖态侧区 → 回到 Launcher；Back 不关闭 Tab，不切换 Paradigm；Launcher 上 Back 无操作；从 Launcher 打开的 Solo 按 Back 回到 Launcher

## 3. 布局
### 3.1 Launcher
```
┌────────────────────────────────────────────────────────── [周日 14:32 ▾] ┐  40dp 角落行
│   ┌──┐   ┌──┐   ┌──┐   ┌──┐   ┌──┐   ┌╌╌┐    图块 88×92：图标 56 + caption  │
│   │⊞ │   │⛨ │   │⚙ │   │  │   │  │   ┆＋┆    每列 104，最多 10 列（≤976）  │
│   └──┘   └──┘   └──┘   └──┘   └──┘   └╌╌┘    网格顶部对齐、水平居中         │
│  工作台   代理   设置   Brave  Gboard  添加                                  │
└───────────────────────────────────────────────────────────────────────────┘
```

- **外观**：背景为 `surface`；不放标题、口号、"继续工作"卡片；内置图块把 glyph 放在 `primaryContainer` 上。与三方应用重名时，内置图块显示为"Workflow 设置"；有待确认请求时，工作台图块带 8dp 徽点
- **长按菜单**（锚定在图块上，每项带图标）：打开 · 在单独的会话中打开（代理/设置）或 新建 Session（工作台）┆ 应用信息（仅三方）· 从 Apps 移除。
- **排序**：长按后拖动超过 slop 即进入排序；被拖图块放大到 1.08 并带阴影，其他图块以弹簧动画让位。
- **添加应用**：宽度 ≥ 600dp 时为 560dp 宽、最高 80% 的 sheet；更窄时全屏；顶部 40dp 搜索框；每行 44dp，包含 32dp 图标、名称、Checkbox，勾选即生效；右上角有"完成"；不显示包名；只在两个应用同名时用 caption 标出来源

### 3.2 Workbench 区域模型
- **外观**：窗口底色为 frame。每个区域是一张 `surface` 卡片（`md` 圆角），区域之间以及与窗口边缘都留 4dp 缝；Tab 行放在 frame 上，激活 Tab 与下方内容同色相连；焦点 Stack 的激活 Tab 顶部显示 2dp `primary` 指示条；除此之外不画焦点边框
- **停靠规则**：按空间是否够用来决定，不设固定断点；侧栏（文件浏览器 / 对话列表）：只要中心区还能 ≥ 360dp 就停靠，否则变为左侧抽屉；辅助区（对话面板 / 文件侧栏）：侧栏停靠之后，中心区仍 ≥ 360dp 才停靠；否则从右缘滑入覆盖层，宽 min(400, W−48)、elevation 3，点外部或 Back 关闭，状态保留。这与 product.md "窄屏下辅助区为覆盖层"一致

| 窗口 | Files | Chat |
| --- | --- | --- |
| 1177 横 | 264 ｜ ≈537 ｜ 对话 360，全部停靠 | 264 ｜ ≈497 ｜ 文件 400，全部停靠 |
| 960 横 | 264 ｜ 684；对话为覆盖层（收起侧栏后可停靠） | 264 ｜ 684；文件为覆盖层 |
| 736 竖 | 264 ｜ 460；对话为覆盖层 | 264 ｜ 460；文件为覆盖层 |
| 区域（dp） | 默认 | 最小 | 最大 |
| --- | --- | --- | --- |
| 侧栏 | 264 | 200 | 40% W |
| 辅助区 | 360（对话）/ 400（文件） | 300 | 55% W |
| 中心区 | 余量 | 宽 360 | — |
| 编辑器 Stack | — | 240 × 120（含 Tab 行） | — |
| 底部 Stack | 列高 35% | 36（仅 Tab 行，即收起） | 列高 − 编辑器最小高度 |

- **分隔条**：平时就是那条 4dp 的缝；按下时在缝中显示 4×32dp 的 `primary` pill 手柄；触控区宽 20dp。沿分隔方向移动超过 slop 才开始拖动，否则把触摸交给内容；拖动中 Compose 区域实时跟随；WebView 与 sora 在松手后防抖 100ms 再重排；拖到最小尺寸的 50% 以下即吸附为收起（侧区收到 0，底部收到只剩 Tab 行），并触发 `CLOCK_TICK`；双击分隔条恢复默认比例；比例按 Session 持久化；窗口尺寸变化时按比例重算，再夹到最小/最大值之间
- **最大化 Stack**：该 Stack 临时占满整个 Workbench，行内出现 `⤡` 用于还原。最大化属于布局状态，会持久化。

- **Paradigm 切换**只改变各区域的权重和位置：不重建对话、不重开文件，回到 Files 时布局原样恢复。

### 3.5 Solo 与窄屏
- **Solo**：单个面板占满窗口；header 为左上簇 + 面板名（`titleSm`）+ 外提按钮 + ⋯ + ⚙；内容最大宽 840dp，居中；在 Solo 中打开文件（如"编辑配置"）时，该 Session 转为 Files，原面板成为编辑器 Stack 中的一个 Tab（见 §8-6）
- **宽度 < 600dp**：侧栏为带 scrim 的模态抽屉，宽 min(320, 0.85W)；辅助区为全宽覆盖层；中心区只显示焦点 Stack，行首有 `[1/3 ▾]` 切换器；布局树不变，窗口变宽后恢复；外提按钮最多保留 2 个；底部 Stack 在没有焦点时收起为 Tab 行

## 4. 组件
### 4.1 StackTabBar
- **Tab**：高 36dp，内边距 10/4，宽 72–220dp；内容依次为 16dp 类型图标 · `label` 标题（末尾省略）· 24dp 尾槽；同名文件在标题后附 caption 显示父目录名
- **尾槽**：有草稿时显示 8dp 圆点（焦点 Stack 中为 `primary`），否则显示 16dp ×。触屏没有 hover，所以每个 Tab 都显示尾槽；点圆点即关闭，不需要确认，草稿作为 Working Resource 保留
- **溢出**：Tab 行横向滚动，两端有 16dp 渐隐；激活 Tab 自动滚入视野；溢出时出现 `⌄n`，展开本 Stack 的 Tab 列表；超过 8 项时带搜索
- **手势**：点按激活；长按 300ms 拾起（`LONG_PRESS` 触感），原地松手弹出菜单，拖动则进入拖放；再次打开已打开的资源时，聚焦已有 Tab 并高亮脉冲一次

### 4.2 文件树
- **行**：高 32dp，每级缩进 12dp；20dp 槽内放 16dp chevron；16dp 图标 + `label` 名称；尾部 6dp `primary` 草稿圆点；已打开的文件用 500 字重；选中项为 `secondaryContainer` pill（`sm`，左右内缩 4dp）；显示 1dp 缩进线；行内不放 `…` 按钮
- **跟随编辑器**：自动展开祖先目录，并滚动到当前编辑器对应的文件。
- **隐藏与格式**：`.workspace/` 始终隐藏，打开"显示隐藏文件"也不显示；应用的原子写入 / 备份文件（`*.bak` 等）绝不出现在工作区；应用写出的 JSON 一律用 2 空格缩进格式化
- **行内编辑**：新建与重命名在行内完成，输入框高 28dp；Enter 或 ✓ 提交，Back 取消；名称非法时只显示红框和简短原因。
- **确认**：删除时确认"删除「x」？"；拖放移动时确认"移动到「y」？"。
- **长按菜单**：打开 · 在右侧拆分中打开 ┆ 新建文件 · 新建文件夹 · 上传…（仅文件夹）┆ 重命名 · 复制 · 移动到… · 删除 ┆ 复制路径 · 复制相对路径 · 附加到对话 · 在终端中打开 · 用其他应用打开。

### 4.3 编辑器
- **外观**：sora 使用 `mono`；gutter 行号为 `onSurfaceVariant`；当前行 `surfaceContainerLow`；选区 primary 25%；代码文件默认不换行，md/txt 默认换行；不显示 minimap、面包屑、状态行；JSON 的 key 与 value 必须高亮区分
- **查找条**（40dp）：查找 · ▸替换 · ↑↓ · n/m · Aa · .* · ×。
- **冲突条**（36dp，`tertiaryContainer`）："磁盘版本已更改" [保留我的] [使用磁盘版本] [对比]。[对比] 打开只读 diff Panel，宽度 ≥ 720dp 时左右并排，否则上下内联。
- **图片**：默认适应窗口，可双指缩放；双击在适应与 1:1 之间切换。
- **二进制或过大文件**：居中显示"无法作为文本打开" + [用其他应用打开]。

### 4.4 终端
- **基础**：xterm 使用 `mono`，内边距 4dp，细的覆盖式滚动条；Tab 标题取 OSC 标题，没有则为"终端 n"。
- **特殊键行**：键位：`Esc Tab Ctrl Alt │ ← ↓ ↑ → │ Home End PgUp PgDn │ | ~ / - _ │ Del ^C ^D ^Z │ F1…F12`；组间距 8dp，整行可横向滚动；键为 `surfaceContainerHigh`、`xs` 圆角，最小宽 40dp；终端有焦点且 IME 可见时显示；也可以设为常驻
- **修饰键**：Ctrl/Alt 单击为单次生效（`secondaryContainer`）；双击锁定（`primary` 填充 + 下划线）；锁定时再点一次解除；方向键长按连发
- **链接**：可见区域内检测到的 URL 和路径常驻虚线下划线（触屏没有 hover），按下时变为实线；抬起即打开：URL 交给系统浏览器；`path[:line[:col]]` 在焦点编辑 Stack 中打开并定位；相对路径按终端当前 cwd（OSC 7）解析，`~` 指向环境内的 home
- **长按**：进入选择模式，显示手柄和浮动工具条：复制 · 粘贴 · 全选。
- **进程结束**：内容变暗，底部一行"已结束" [重启] [关闭]。

### 4.5 对话消息流
- **布局**：内容最大宽 720dp，居中；水平边距 16dp（360dp 面板中为 12dp）；轮次之间 24dp，轮内 8dp；两条消息相隔 30 分钟以上时插入居中的 caption 时间分隔
- **用户消息**：右侧气泡：`primaryContainer`，`lg` 圆角，内边距 12×8，最大宽 85%；超过 10 行时折叠为"显示更多 ⌄"；附件以 64dp 缩略图显示在气泡上方；长按：复制 · 从这里分叉（后端支持时）
- **助手消息**：无气泡，按 `chat` 样式渲染 Markdown；流式输出不做逐字动画；代码块使用 `surfaceContainerHighest`、`sm` 圆角，带 28dp 头部（语言 + ⧉）。代码块、表格、块级公式均在块内横向滚动；公式用原生 Canvas 绘制，支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`；未完成或不支持的语法保留为可读文本；本地路径链接：Files 中在焦点 Stack 打开，Chat 中在文件侧栏打开（必要时自动展开侧栏）
- **系统通知**（额度、压缩、错误）：居中 caption，两侧加 hairline；错误通知附 [重试]。
- **滚动**：在底部时跟随新内容；上滑后停止跟随，composer 上方出现 36dp 的 ↓；有待确认项时，该按钮变为"1 个待确认 ↓"；真实可见块键、像素偏移与是否跟随底部在滚动停止后提交给 Workspace Engine，面板切换和进程重建后恢复，必要时先加载较早历史
- **实现**：消息流、Markdown 正文、表格、代码、审批卡与 composer 均为原生 Compose；公式通过 Compose Canvas 绘制，无聊天 WebView/JavaScript 桥。一个按消息与块虚拟化的 LazyColumn 使用稳定键；后台合并流式更新、缓存不变消息。原生文本选择、块内横向滚动与代码复制不依赖 HTML。

- **轮次头**（28dp，`label`，`onSurfaceVariant`）：

  | 状态 | 表现 |

  | 已停止 | "已停止 · X ›" |
  | 失败 | error 图标 + [重试] |

- **过程块**：中间消息与活动行按时间顺序排列；活动行：28dp 高，16dp 图标 + 单行摘要，点按展开；连续的同类工具调用合并为一行；思考：进行中为"思考中…"并做 alpha 呼吸；完成后为"已思考 12s ›"，展开显示推理摘要；计划：显示"计划 2/5 ›"，展开为清单
- **展开后的详情**：

  | 类型 | 内容 |
  | --- | --- |
  | 命令 | `surfaceContainerLow` 块：等宽命令、✓/✕、输出前 12 行（可展开全部） |
  | 文件编辑 | 文件列表 + 增删行数，点按打开 diff |
  | 搜索 | 查询词 + 结果链接 |
  | MCP | 工具名 + 折叠的参数 |
  | 未知类型 | "未识别的活动 ›"，展开为保真 JSON |

- **文件更改卡**：`md` 圆角，`outlineVariant` 描边；44dp 头部带 [查看更改]；只有后端支持时才出现 [撤销]；每个文件一行 36dp：目录用 caption，文件名用 body，行尾是 success/error 色的等宽 `+n −n`；超过 3 行时折叠
- **操作行**：32dp 图标，依次为 复制 · 分叉（后端支持时）· ⋯（复制为 Markdown）。

### 4.7 审批与提问卡
- **位置**：原生卡片放在消息流末尾，固定在 composer 上方；上滑时仍可见；卡片最多占列高 50%，超出部分在卡内滚动；多张卡按到达顺序堆叠
- **收尾**：做出决定后，卡片收成 transcript 中的一行记录（如"已批准 · 运行 git status"）；轮次被取消时标为"已失效"。
- **外观**：`md` 圆角，`surfaceContainerHigh` 底，1dp warning 描边。头部为 18dp 图标 + 标题，标题取值：运行命令 / 修改文件 / 权限 / 需要你回答 / 工具请求。
- **内容**：命令：等宽显示，超过 6 行折叠；cwd 只在不是工作区根目录时显示；附上代理给出的理由；文件修改：文件与增删行数，[查看] 打开 diff
- **按钮**：严格按请求中允许的决策生成，例如 [批准]（Filled）· [本对话内允许]（Tonal）· [拒绝] · [⌄]（中止本轮等其他选项）；用"本对话"而不是"本会话"，以免与 Session 混淆；不预选任何按钮；初始焦点不在"批准"上；硬件键盘 Enter 也不会触发批准
- **提问 / MCP elicitation**：问题 + 选项 chip（单选或多选）+"其他"自由文本；必答项未完成时 [提交] 禁用；表单支持 string / number / boolean / enum，其他类型退化为 JSON 编辑框
- **未知请求**：显示为"未识别的请求"，[详情] 中是保真 JSON，并按协议提供回复或拒绝。绝不自动应答。

- **卡片**：`surfaceContainerHigh`、`xl` 圆角、外边距 8dp，位于 IME 之上。软键盘 Enter 换行；硬件键盘 Enter 发送，Shift+Enter 换行。

- **附件条**：图片为 56×56 缩略图；文件为 40dp chip，名称最宽 160dp；右上角 20dp ×；上传中显示进度环；失败时加 error 描边和 ↻

- **发送键**（36dp 圆形）：

  | 空，或后端未就绪（未登录 / 无模型） | 禁用 |
  | 有文字 | `primary` ↑ |
  | 进行中，输入为空 | ■ 停止 |
  | 进行中，有文字 | [■][↑]：↑ = 引导；长按 ↑ 选择"排队到下一轮" |

  - 已排队的消息以 chip 显示在文字上方，可以移除。
  - 发送 ↔ 停止之间做 Expressive 形状变换。
- **模型滑块**：弹层锚定在模型 chip 上方。每个模型占一段，段内的档位就是推理强度；最多放 4 个模型（最近使用 / 推荐）；拖动时逐档吸附，每档触发 `CLOCK_TICK`；标题和 chip 实时更新；选择对下一轮生效，不需要确认；› 打开完整模型列表，选中后滑块跳到对应位置；点外部或 Back 关闭；档位名称：极低 / 低 / 中 / 高 / 极高

### 4.9 会话视图与归档
- **容器**：宽 ≥ 600dp 时为从左侧滑出的 400dp 模态 side sheet（带 scrim）；更窄时全屏。
- **头部**（44dp）：36dp 搜索框（按名称和资源检索）+ ＋（新建临时 Session）。
- **已命名**：双行 48dp——`titleSm` 名称，caption 列出主要资源（文件名、对话标题），尾部为相对时间；当前 Session 带 `primary` 圆点。
- **临时**：以时间轴呈现：1dp 竖线加节点，按 今天 / 昨天 / 本周 / 更早 分组；每项显示开始时间和主要资源，不写"临时会话"，不显示面板数；越久远越"模糊"：

  | 分组 | 不透明度 | 字重 | 显示的资源数 |
  | --- | --- | --- | --- |
  | 今天 | 1.0 | 500 | 3 |
  | 昨天 | 0.85 | 400 | 2 |
  | 本周 | 0.72 | 400 | 1 |
  | 更早 | 0.62 | 400 | 仅时间 + 首个资源 |

  - API 28 没有 RenderEffect，因此不做真正的模糊。
- **底部与操作**：底部一行"已归档 (n) ›"，进入后每项带 [恢复]。点按切换 Session；长按可命名 / 重命名 · 归档…
- **手动归档**：涉及未保存内容时，弹出 AlertDialog"归档「名称」"，列出受影响的资源（最多 5 个，其余写"等 n 个"）；按钮：[取消] 在左；右侧依次为 [丢弃]（error 文字）· [保留草稿]（Tonal）· [全部保存]（Filled）；不预选任何按钮，点外部不关闭；没有未保存内容时直接归档，并显示 Snackbar"已归档 · 撤销"

### 4.10 拖放反馈
- **拾起**：长按 300ms 并给出触感；源项变为 40% 不透明；拖影为紧凑 chip（图标 + 名称，`surfaceContainerHighest`，elevation 3，`sm` 圆角），显示在手指上方 32dp

| 目标 | 反馈 |
| --- | --- |
| Stack 内容区 | 分 5 区：中心 50%，四边各占外侧 25%。预览为放下后结果区域的矩形：primary 12% 填充 + 2dp primary 描边，`md` 圆角，在区域之间以弹簧动画移动 |
| Tab 行排序 | 2dp × 28dp 的 `primary` 插入竖线，其他 Tab 不让位 |
| 树中的文件夹 | 行高亮为 `primaryContainer`，悬停 600ms 自动展开；松手后需要确认 |
| composer | 2dp primary 描边 + 8% 填充，显示"添加为附件" |
| 终端 | 半透明层，显示"粘贴路径" |

- **拖动中**：靠近列表或 Tab 行两端 32dp 时自动滚动；悬停在收起区域的开关上 600ms，该区域展开；目标无效时拖影显示 ⃠；取消（落在无效处或按 Back）时拖影以弹簧动画回到原位
- **实现**：应用内拖放用 Compose 覆盖层绘制拖影；外部拖入走 `dragAndDropTarget`，反馈与应用内一致。松手时只提交一个 `LayoutOp`。


- **标题与启停**：标题为"代理"，不写内核名。启停是一个形变开关；没有 Root 时变为 [请求 Root]。
- **未启动时**：模式和代理组照常从配置读出显示，但处于禁用态，不加说明句。组的类型只用图标区分（手动 / 自动测速）。
- **节点 chip**：选中项为 `secondaryContainer` + ✓。延迟颜色：< 300ms 为 success，< 800ms 为 warning，更高或超时为 error。
- **冲突提示**：检测到其他 VPN/TUN 时，显示一行 `errorContainer` 横幅"另一个 VPN 正在运行" [查看]。
- **日志与连接**：作为同一 Stack 中的独立 Panel 打开，不带自己的顶栏。
- **没有配置时**：只显示"没有代理配置" [导入配置] [编辑配置]。

### 4.13 设置
- **布局**：面板宽 ≥ 720dp 时分两栏（分类 220dp + 详情）；更窄时逐级进入，返回按钮放在 header 行内。
- **行**：48dp，标题用 `body`，右侧显示当前值（caption）或开关。
- **不出现的内容**：副标题说明、文件路径、tagline，以及 Termux / 配对相关内容。

## 5. 动效
全局使用 `MaterialExpressiveTheme(motionScheme = MotionScheme.standard())`：动画快，不回弹；可感知的动画不超过约 300ms。

| 场景 | spec |
| --- | --- |
| 颜色、透明度、高亮、呼吸 | `fastEffectsSpec` |
| 菜单、tooltip、chip、行展开/折叠（`animateContentSize`） | `fastSpatialSpec` |
| 区域开合、sheet、覆盖层、Paradigm 切换（动画作用于区域权重，不重建内容） | `defaultSpatialSpec` |
| 按钮/ToggleButton 形变、发送↔停止、悬浮球贴边、拖影拾起与回弹、滑块手柄 | Expressive `fastSpatial` / `defaultSpatial` |

- 流式文本不做动画；自动跟随时直接跳到底部，不做平滑滚动。
- IME 相关变化不做动画；系统动画缩放为 0 时直接到终态。
- 触感只用 API 28 可用的 `LONG_PRESS`、`CLOCK_TICK`、`KEYBOARD_TAP`。

## 7. 无障碍与输入
- **对比度**：文字 ≥ 4.5:1，图标与边界 ≥ 3:1；时间轴最淡的一组也要 ≥ 3:1，因此不透明度下限取 0.62；禁用态按 M3 的 38%
- **字号缩放**：支持到 1.3。行高取 max(token, 文字高 + 内边距)，不裁切文字；Tab 标题只做末尾省略。
- **TalkBack**：Tab 使用 tab 角色，读出"已选中 / 未保存"；分隔条为可调节控件，提供"增大 / 减小 / 收起"动作；每种拖放能力都有对应的 custom accessibility action；回复完成时每轮只播报一次；审批卡出现时以 polite 方式播报
- **焦点顺序**：左上簇 → 各区域（按阅读顺序）→ 右上簇。
- **RTL**：整体镜像，编辑器与终端保持 LTR。
- **硬件键盘快捷键**：

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+S / Ctrl+Z / Ctrl+Shift+Z | 保存 / 撤销 / 重做 |
| Ctrl+F / Ctrl+W / Ctrl+Tab | 查找 / 关闭 Tab / 切换 Tab |
| Ctrl+B / Ctrl+J / Ctrl+Alt+B | 开关侧栏 / 底部 Stack / 辅助区 |
| Ctrl+N / Ctrl+Shift+N | 新建文件 / 新建对话 |
