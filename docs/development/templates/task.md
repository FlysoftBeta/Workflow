# Task objective

Describe one independently deliverable result. Name the checkout, base commit and exclusively owned source paths, then link the product, UX and implementation documents the contributor needs.

Explain the acceptance criteria and required named suites. Identify a dependency or shared contract that must be settled before implementation. For Android work, reserve only the normal shared emulator queue; do not allocate a separate emulator to this task.

Ask for one final handoff containing the committed result, evidence and limits. New subagents start with `fork_turns="none"` and their own bounded packet. The coordinator remains responsible for review and final integration.
