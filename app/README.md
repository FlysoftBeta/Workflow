# Android shell

`:app` connects Android to the Rust Workspace Engine and renders its state. Start with
[`AppGraph`](src/main/java/top/flysoftbeta/workflow/app/AppGraph.kt) for composition and
[`WorkspaceConnectionManager`](src/main/java/top/flysoftbeta/workflow/platform/connection/WorkspaceConnectionManager.kt)
for connection lifetime. Sessions, layouts, drafts, workspace files, environment generations and
service documents remain Engine-owned. The client keeps discardable projections, connection
profiles and the local configuration delivered by the workspace.

The Kotlin source root is `src/main/java/top/flysoftbeta/workflow/`. `app/` assembles the shell and
panel contracts; `feature/` contains independent panels; `platform/` implements Android ports; and
`ui/` contains shared Compose, Sora and WebView adapters. Features do not import one another.
`app/panel/PanelWiring.kt` composes their providers and permits a scoped provider to be supplied by
an acceptance harness without replacing a process-wide service.

Chat rendering lives in `feature/chat/transcript/` and uses native Compose. Only the terminal uses
WebView. Its maintained page and Android input adapter live in `src/main/assets/web/`; the nested
`vendor/` directory is generated by [`web/`](../web/README.md). TextMate grammars, fonts and notices
are offline assets with their upstream attribution. Generated Engine executables, the guardian,
pinned binaries and environment images are staged under `build/generated/` by Gradle; do not edit
those outputs or copy them into source directories.

`src/test/` holds JVM tests. `src/androidTest/` holds instrumented UI, platform and Engine acceptance
tests, including reference-store adapters that must never enter production. `src/debug/` contains
the development design gallery and its manifest entry. Production proxy services have no global
test override: the proxy acceptance UI injects its own provider, and constructs its disposable
executor in `androidTest`.

Run host checks from the repository root while holding the shared build lock:

```sh
flock artifacts/.gradle.lock ./gradlew :app:testEmulatorDebugUnitTest :app:lintEmulatorDebug
```

Instrumented tests require the documented isolated AVD wrapper. Compiling them is not device
acceptance. The [architecture](../docs/implementation/architecture.md),
[protocol](../docs/implementation/protocol.md), [UI guide](../docs/ux/README.md) and
[testing guide](../docs/development/testing.md) define the boundaries and acceptance matrix.
