# Agent protocol adapters

`:agent` is a pure Kotlin/JVM library for Codex App-Server and Claude Code. It translates vendor
messages into neutral conversation state while preserving raw unknown methods, fields,
notifications and server request IDs. Approval requests remain pending until the user answers;
Codex initialization always carries the explicit user-reviews-approvals setting. This module
does not depend on Android, `:core` or `:proxy`.

The source root is `src/main/kotlin/top/flysoftbeta/workflow/agent/`. `model/` owns neutral events,
items and reduction; `codex/` and `claude/` own vendor mapping and backend state; `transport/`
implements the protocol transport; `process/` defines the injected process-launch port; and
`json/` supplies shared JSON helpers. Android implements the process port through Engine-managed
environment processes. There is no production host-agent fallback.

`src/main/resources/protocol/` preserves the pinned vendor schemas and inventories used to check
adapter coverage. [`protocol-coverage.md`](protocol-coverage.md) is generated by
`ProtocolCoverageTest`; edit the coverage declarations or pinned inputs and regenerate it instead
of hand-editing the table. `src/test/` holds deterministic replay fixtures and an opt-in real CLI
smoke runner. Smoke results and real account acceptance are different evidence from unit tests.

Run the deterministic suite from the repository root:

```sh
flock artifacts/.gradle.lock ./gradlew :agent:test
```

When intentionally updating the coverage golden file, add `-Pagent.updateGolden=true`. The
`smoke` Gradle task is opt-in; its arguments and prerequisites are documented in the test source
`smoke/SmokeMain.kt`. Generated classes, test reports and JARs belong in the ignored `build/`.
The [agent integration guide](../docs/implementation/agents.md) explains the supported protocol
surface and the [testing guide](../docs/development/testing.md) describes acceptance limits.
